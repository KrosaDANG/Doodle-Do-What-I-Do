# Doodle-Do-What-I-Do: Mini-Game Version

This branch contains the interactive mini-game version of the project.

### New Files Added:
* **sabkuchmilgaya.html**: The main entry point for the game.
* **sabkuchmilgayagesture.js**: Handles the specific hand/body gestures for game logic.
* **sabkuchmilgayagesturereaction.js**: Controls the visual and audio reactions within the game.

### How to Play:
1. Open `sabkuchmilgaya.html` in a web browser.
2. Allow camera access when prompted.
3. Follow the on-screen gestures to interact with the game.
